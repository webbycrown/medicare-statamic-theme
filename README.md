# Medicare - Statamic Starter Kit

Medicare is a modern Statamic starter kit designed for healthcare providers, clinics, hospitals, wellness centers, and medical practices. It offers a polished website experience with reusable page sections, medical service showcases, blog content, and built-in appointment and contact forms.

## Pages of Medicare

The starter kit includes a complete set of pages for building a professional healthcare website:

- **Home Page**
- **Blogs**
    - Blog Listing
    - Blog Details
- **Services**
    - Service Listing
    - Service Details
- **Doctors**
    - Team Member Listing
    - Team Member Details
- **About Us**
- **Appointment**
- **Contact Us**
- **Awards**
- **404 Page**

## Collections

Organize your content using built-in Statamic collections:

- **Pages** – Manage your website pages and navigation.
- **Services** – Showcase medical treatments, specialties, and care offerings.
- **Blogs** – Publish health articles, wellness guidance, and care tips.
- **Specializations** – Organize doctor departments and medical expertise.
- **Team Members** – Feature doctors, specialists, and healthcare professionals.
- **Testimonials** – Highlight patient reviews and success stories.
- **Tags** – Reusable tags for organizing content.

## Features of Medicare

- **Flexible Page Builder** – Easily create modern pages with reusable content sections.

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit) to get started with Medicare.
Make sure you're running **Statamic 5.x** for compatibility.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/medicare-statamic-theme
```

### Installing via the Statamic CLI Tool

If you have the [Statamic CLI Tool](https://github.com/statamic/cli) installed, create a new Statamic installation with Medicare in one command:

```bash
statamic new my-site webbycrown/medicare-statamic-theme
```
